# Battlecode tooling

This branch reorganises the UNSW Battlecode bots and adds a reproducible Python
runner and offline analytics package. The active bot is [src](src); archived bots
are under [bots](bots), maps under [maps/train](maps/train), and generated runs
under `results/runs/`.

Start with [docs/USAGE.md](docs/USAGE.md). Discovery constraints and unavailable
replay metrics are recorded in [docs/DISCOVERY.md](docs/DISCOVERY.md).
